# SozoRock platform introductions

Four short, text-led introductions to The SozoRock Foundation, SozoRock Health, Place Intelligence, and CB-CAP. Each film is 12 seconds at 1080 × 1080 pixels and 30 frames per second. All messaging is visible on screen; no audio is required.

Install dependencies with `npm ci`, then use `npm run studio` to edit the compositions. Render a film with:

```sh
npm exec remotion -- render src/index.tsx CBCAP out/CBCAP.mp4
```

Available composition IDs: `Foundation`, `Health`, `PlaceIntelligence`, and `CBCAP`.

These are product introductions, not recordings of completed institutional workflows. Public evidence, scenario estimates, and human review remain distinct in the products.
