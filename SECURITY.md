# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
[contact@sozorockfoundation.org](mailto:contact@sozorockfoundation.org?subject=Security%20report).
Include the affected URL or component, a concise description, reproduction steps,
and the impact you observed. Do not include passwords, API keys, health information,
or other personal data in the report.

Please do not open a public issue for an unpatched vulnerability. We will acknowledge
good-faith reports and coordinate remediation and disclosure directly. The SozoRock
Foundation does not currently operate a paid bug-bounty program.

## Scope

The supported public surfaces are:

- `https://www.sozorockfoundation.org`
- `https://sozorockfoundation.org`
- this repository's default branch

Reports about third-party services should be sent to the relevant provider unless the
issue is caused by the Foundation's configuration or integration.
