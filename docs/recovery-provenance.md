# Parent-site recovery provenance

The approved parent website was completed and validated in ChatGPT Sites, but its final downloadable source bundle was not committed to the Foundation repository and later became inaccessible through the workspace download control and available programmatic retrieval surfaces.

This repository copy is therefore a forensic reconstruction of the approved implementation, not a claim that the original generated source bytes were recovered. The reconstruction is grounded in:

- the approved published Sites URL;
- browser screenshots of the final home/in-focus/platform/engagement/footer states;
- the final `design-qa.md` and `quality-audit.md` acceptance records;
- the last recoverable earlier HTML/CSS/JS prototype used only as a structural scaffold;
- the approved redesign brief and publication records.

The SozoRock Health In Focus image was recovered exactly from the approved Health site repository as `hero-community-desktop-v2.webp`. Recovery verified the source file size as 73,222 bytes and its Git blob SHA as `d1f56687d982e40209d1e01e97fb0f5d9cb0ce68` before committing it to `site/assets/health-community.webp`.

The parent-site source is intentionally separated from all subdomain products and publication-access backend behavior.
